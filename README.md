Zirkbe Synergy Limited Website

A modern, responsive corporate website for Zirkbe Synergy Limited, showcasing the company's renewable energy, solar power, electrical engineering, and power infrastructure solutions.

Features

Responsive layout for desktop, tablet, and mobile devices

Light and dark theme toggle

Animated hero section

Company information and services

Project gallery with category filters

Project viewing modal

Testimonials section

Contact form and Get a Quote modal

Scroll reveal animations

Technologies Used

HTML5

CSS3

JavaScript

Project Structure

index.html — Main website page

cssfiles/ — Stylesheets and theme variables

jsfiles/ — JavaScript functionality

images/ — Website images and visual assets

Local Development

Clone or download this repository.

Open the project folder in Visual Studio Code.

Run index.html using the Live Server extension.

Deployment

The website will be deployed using GitHub and Vercel.
